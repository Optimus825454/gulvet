# Gülvet Hayvancılık - Görüntü Dosyaları

Bu klasör, web sitesinde kullanılan tüm görüntü dosyalarını içermektedir.

## Klasör Yapısı

- `/images/logo.png` - Ana logo dosyası
- `/images/logo-light.png` - Açık zemin için logo dosyası
- `/images/animals/` - Hayvan fotoğrafları
- `/images/blog/` - Blog görselleri
- `/images/team/` - Ekip üyelerinin fotoğrafları
- `/images/certificates/` - Sertifikalar ve belgeler

## Görüntü Formatları ve Boyutları

- **Logo**: PNG, şeffaf arkaplan, 240x80px
- **Hero görselleri**: JPG/WEBP, 1600x800px
- **Hayvan küçük resimler**: JPG/WEBP, 600x400px
- **Blog görselleri**: JPG/WEBP, 800x500px

## Görüntü Optimizasyonu

Tüm görsellerin web için optimize edilmesi önerilir:
1. JPG dosyaları için %80 kalite
2. PNG dosyaları için renk paletini optimize edin
3. Mümkünse WEBP formatını kullanın (daha küçük dosya boyutu)

Optimizasyon için çevrimiçi araçlar:
- [TinyPNG](https://tinypng.com/)
- [Squoosh](https://squoosh.app/)
- [Compressor.io](https://compressor.io/)
